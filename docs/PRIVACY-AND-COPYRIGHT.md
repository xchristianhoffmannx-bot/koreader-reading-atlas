# Privacy and copyright

## What leaves your computer

| What | To whom | When |
|---|---|---|
| Text of the chapters you have read (in requests of about 30,000 characters), the current known characters and events | The AI provider you chose (OpenAI, Anthropic, Google Gemini) or, with the Codex CLI, OpenAI under your Codex login | every time new text has to be processed |
| Place names found in the book (for example "London, England") and your `nominatim_contact` | OpenStreetMap Nominatim | only for real-world places, results are cached |
| Nothing | Natural Earth | the land polygons are downloaded once from a public GitHub address |
| A short description of a character's appearance, a style reference and an earlier image (Codex) | Your image provider | only if you turn portraits on |

Nothing is sent to the authors of this project. There is no telemetry. API keys are read from environment variables or from the file that koreader-reading-recap already protects with Windows DPAPI; this project never writes a key to disk.

Check your provider's data-retention and training terms. API calls are usually treated differently from consumer chat products; the code sets `store: false` for OpenAI chat requests.

## What is stored, and where

Everything is in your data home (`~/ReadingAtlas` or `READING_ATLAS_HOME`), never in this repository: chapter states (short facts in the model's own words, each with a source paragraph; the book text itself is not stored), portraits, maps, a cache of the EPUB files copied from your reader, and the finished pages.

The only place the book text is kept is the EPUB you already own and a copy of it in `book-cache/`.

## Copyright

- Use DRM-free EPUB files that you own. This project does not help remove DRM.
- The atlas stores and shows short facts and paraphrases. The prompts ask for short facts in the model's own words (the profile sentences explicitly forbid verbatim quotation), and each fact keeps only a reference ("chapter, about 45 %"), not the sentence.
- A page contains an interpretation of a book (characters, relationships, timeline). Treat it as a private reading aid. If you publish a page, think about the rights of the author and publisher first. The authors of this project do not publish pages of copyrighted books.
- Portraits are generated by an AI from a short description. They are labelled as such in the page. The terms of your image provider decide who may use them.
- Maps: Natural Earth is public domain. OpenStreetMap data is ODbL and the page carries the attribution. Maps from Wikimedia Commons keep their licence and author in the page; only freely licensed files are accepted.

## Before you publish anything yourself

Run `python tools/check_private.py --terms <your-terms-file>` over any folder you want to share. It finds keys, absolute home paths, e-mail addresses, book and image files and any term you list (names, book titles, character names).
